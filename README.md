## 儿歌《校园真美好》

```
柳条摇，云朵飘，
枫叶红，景色好。
椅子摆好路灯照，
胡子爷爷夸我好。
穿好鞋，轻轻跑，
隐蔽角落不乱抛。
少烦恼，勤环保，
校园美得流连忘返！
```
